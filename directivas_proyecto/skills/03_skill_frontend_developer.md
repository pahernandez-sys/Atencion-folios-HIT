# Skill: Especialista en Desarrollo Web Frontend & GitHub
## Rol Técnico de Frontend

### 1. Definición del Perfil y Misión
El **Especialista en Desarrollo Web Frontend** diseña e implementa la interfaz web accesible y fluida para que los contratistas reporten incidencias de HIT desde cualquier navegador o dispositivo móvil, con despliegue continuo en **GitHub Pages**.

---

### 2. Áreas de Especialidad y Capacidades

#### A. Arquitectura Web en GitHub Pages
* Desarrollo de Single Page Applications (SPA) estáticas, ultra-ligeras y sin dependencias pesadas de servidor.
* Estructuración de flujos de integración continua (CI/CD) con GitHub Actions para despliegue automatizado.
* Optimización de rendimiento web: tiempos de carga inferiores a 1.5s en redes 3G/4G móviles.

#### B. Procesamiento de Archivos en el Navegador (Client-side Parsing)
* Integración de `SheetJS (xlsx)` para lectura de archivos binarios en memoria mediante `FileReader API`.
* Filtrado de filas vacías y conteo dinámico e instantáneo de registros para alimentar el campo de `Numero de folios en excel`.
* Detección y manejo visual de errores en el formato del archivo antes de iniciar la subida de datos.

#### C. Diseño de Interfaz de Usuario y Ergonomía (UI/UX)
* Implementación de componentes con Tailwind CSS: formularios limpios, botones grandes accesibles para pantallas táctiles de campo.
* Zonas interactivas de Drag & Drop para carga de archivos con retroalimentación visual de progreso (spinners, barras de porcentaje).
* Gestión de alertas y pantallas de confirmación claras que muestran el Folio Linkaform generado para tranquilidad del usuario.
